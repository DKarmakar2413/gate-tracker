Quick Setup

  1. Create a Google Sheet and add columns: Subject,Topic,Status,PlannedDate,EstimatedHours,Notes.
  2. Open Extensions → Apps Script and paste the Apps Script file apps_script.gs.
  3. Deploy the Apps Script as a web app: Execute as: Me, Who has access: Anyone, even anonymous. Copy the URL.
  4. Paste that URL into the AppsScript endpoint field below and click Save endpoint.
  5. Publish the sheet to CSV (optional): File → Publish to web → choose sheet → CSV → copy link.
  6. Deploy this site to GitHub Pages (see README).
